# 트랙 C 결과 한 벌 — 패킹 알고리즘

팔레트 1200×800 · 최대 적재 1300mm · 격자 10mm

> 전부 `ros2 run packing_algo report` 한 번으로 다시 뽑힌다. 표와 그림이 **같은 코드 상태**를 가리킨다는 뜻이다.

## 1. 적재 과정 — Isaac 과 대조할 것

★ 시드 **22** 으로 그렸다. 30시드 중 **적재율이 중앙값에 가장 가까운** 판이다 — 기본 시드를 그냥 쓰면 그 판이 우연히 높거나 낮아 아래 표와 어긋난다. 평균이 아니라 중앙값을 쓴 이유는, 평균에 맞추면 좋아 보이는 쪽으로 기울 수 있어서다.

| 파일 | 무엇 |
|---|---|
| `01_stack.mp4` | 박스가 하나씩 놓이는 전 과정 |
| `02_stage_01.png` | 적재 1개 시점 |
| `02_stage_05.png` | 적재 5개 시점 |
| `02_stage_10.png` | 적재 10개 시점 |
| `02_stage_15.png` | 적재 15개 시점 |
| `02_stage_20.png` | 적재 20개 시점 |
| `02_stage_26.png` | 적재 26개 시점 |

**Isaac 과 이렇게 비교한다.** 왼쪽 3D 그림의 박스 위치·색(3호 파랑 / 4호 주황 / 5호 초록)이 Isaac 팔레트와 같아야 한다. 다르면 좌표 계약(`frames.py`)이나 실측 pose 회신을 의심한다.

오른쪽 위 heightmap 은 **알고리즘이 믿고 있는 팔레트 상태**다. 실제 더미와 다르면 `update_heightmap` 에 계획값이 들어간 것이다 (계약: 실측값만).

오른쪽 아래 곡선이 두 개인 이유 — 분모가 다르다:

- **실제 높이 기준** (§7.8 정본): 층이 올라갈 때 분모가 뛰어 **뚝 떨어진다.** 정상이다.
- **용량 기준** (max_stack 고정): 단조 증가. 발표에서 설명하기 쉽다.
- 포화까지 채우면 둘이 만난다 — 최종 68.4% / 66.3%.

## 2. 얼마나 잘 쌓나 — 베이스라인 대비 (`03_compare_baseline.png`)

시드 30개 · 팔레트 포화까지 · 두 패커에 **같은 박스 시퀀스**

| 알고리즘 | 적재 개수 | 적재율 |
|---|---|---|
| 제안 (heightmap) | 25.7 | **66.7%** |
| 베이스라인 (순차) | 18.0 | **47.8%** |

**차이 +19.0%p.** 베이스라인은 회전 없이 좌하단부터 처음 들어가는 자리에 넣는다 — '아무 생각 없이 쌓기'의 대조군이다.

## 3. 오차를 얼마나 견디나 (`04_robustness.png`)

시드 30개 · 실측 pose 가 계획에서 벗어났을 때

| 조건 | 적재율 | 오차없음 대비 |
|---|---|---|
| 오차 없음 | 66.7% | +0.0%p |
| 위치 ±3mm | 66.7% | +0.0%p |
| 위치 ±10mm | 65.6% | -1.2%p |
| 위치 ±3mm · yaw ±3° | 66.7% | +0.0%p |
| 위치 ±3mm · yaw ±5° | 66.7% | +0.0%p |
| 위치 ±3mm · yaw ±8° | 62.6% | -4.2%p |
| 위치 ±3mm · yaw ±15° | 57.1% | -9.7%p |
| 위치 ±10mm · yaw ±15° | 59.5% | -7.2%p |

**위치는 널널하고 yaw 가 아프다.** `update()` 가 셀 격자(10mm)로 반올림하므로 위치 ±3mm 는 계획과 같은 칸에 떨어진다. 반면 yaw 는 허용치 5° 를 넘는 순간 외접 사각형으로 부풀려 기록돼 그 박스가 실제보다 넓은 자리를 먹는다.

→ **로봇에 요구할 값: 놓는 순간 yaw 오차 ±5° 이내.** 위치는 ±10mm 여유.

## 4. 실시간으로 보려면

```bash
ros2 run packing_algo algo_service_node --ros-args \
    -p use_sim_time:=true -p snapshot_path:=/tmp/algo_state.json
ros2 run packing_algo live_view -p /tmp/algo_state.json -z b
```

위 그림과 같은 화면이 실시간으로 갱신된다. Isaac 창 옆에 띄워 두고 본다.
