# 홍보영상 기획 프롬프트 v2 — "사람을 향하는 기술"

> Project Palletris · 2026-08-28
> **v1과의 차이**: v1(`홍보영상_제미나이_프롬프트.md`)은 우리 실행 영상을 자르는
> *편집 지시서*를 뽑는 실무용이었다. v2는 **감성 브랜드 필름 기획**이다 —
> 기술 용어를 한 개도 쓰지 않고, 플래그십 광고의 톤으로 스토리보드와 스크립트를 뽑는다.
> 둘은 대체 관계가 아니다. **v2로 이야기를 정하고, v1으로 실제 컷을 붙인다.**

## 0-0. 이 영상이 서 있는 자리 — 기획의 축

이 시스템의 로봇은 **주행하지 않는다.** 물류센터 상차 라인에 서서
**상자를 들어 쌓는 로봇 팔**이다. 그래서 감성 메시지의 축을 여기에 잡았다.

| | 흔한 로봇 광고의 축 | **Palletris 의 축** |
|---|---|---|
| 위험의 정체 | 언젠가 일어날 수 있는 사고 | **매일 반복되는 무게** |
| 지키는 대상 | 불특정 다수 | **밤새 상자를 드는 한 사람의 허리와 어깨** |
| "안전"의 뜻 | 사고를 막는다 | **사고가 아니라 마모를 막는다** |

> **★ 이쪽이 더 강한 이야기다.** 사고를 막는 안전은 "일어날 수도 있는 일"을 다루지만,
> 우리가 막는 것은 **이미 매일 일어나고 있는 일**이다.
> 광고에서 극적인 것은 후자다 — 관객이 이미 본 적 있는 장면이기 때문이다.
>
> 그리고 이 축이 요구사항의 **"기술이 아닌 사람을 향하는 안전"** 과 정확히 겹친다.
> 로봇의 성능이 아니라, 그 성능이 **누구의 10년을 대신 지는가**를 말한다.

## 0. 톤앤매너 정의 (프롬프트에 그대로 포함)

```
[톤앤매너 — 이 영상이 되어야 하는 것]

레퍼런스: Apple 제품 필름 · Tesla 플래그십 광고 · Nike "Dream Crazy"
          → 제품 사양을 나열하지 않는다. 제품이 사람의 하루를 어떻게 바꾸는지만 보여준다.

핵심 명제 : "우리는 로봇을 만들지 않았습니다. 누군가의 내일 아침을 만들었습니다."

절대 규칙 5개
  1. 기술 용어 **전면 금지**. 다음 단어가 화면·나레이션·자막에 한 번도 나오면 안 된다:
     센서 / 카메라 / 알고리즘 / AI / 인공지능 / 데이터 / 시뮬레이션 / 좌표 / 제어 /
     최적화 / 자동화 / 시스템 / 솔루션 / 플랫폼 / 정확도 / 효율 / 처리량 / 퍼센트(%)
     ※ 숫자 자체를 쓰지 않는다. 이 영상은 성능을 증명하지 않는다.
  2. **사람이 먼저 나온다.** 첫 10초 안에 로봇을 보여주지 않는다.
  3. **로봇을 의인화하지 않는다.** 귀엽게 그리지 않는다. 로봇은 조용한 조연이다.
  4. **문장을 짧게.** 한 문장 12자 이내. 접속사 금지. 쉼표보다 컷.
  5. **비교하지 않는다.** "기존 대비", "더 빠른" 같은 표현 금지. 우열이 아니라 변화다.

시각 언어
  - 색   : 새벽의 청회색 → 아침의 따뜻한 호박색. 이 전환이 영상의 유일한 서사다.
  - 조명 : 자연광. 물류센터의 높은 창, 도크 문틈으로 새는 빛.
  - 렌즈 : 얕은 심도. 배경은 흐리고, 사람의 손과 얼굴만 선명하다.
  - 카메라: 느리게. 급한 컷 금지. 관객이 숨 쉴 시간을 준다.
  - 소리 : 초반 20초는 **현장음만** (컨베이어의 저음, 테이프 소리, 숨소리).
           음악은 로봇이 처음 등장할 때 들어온다.

금지 연출
  - 로봇이 사람과 하이파이브 하거나 손을 흔드는 장면
  - 화면을 가로지르는 스캔라인·홀로그램·HUD·수치 오버레이
  - 빠른 비트의 일렉트로닉 음악, 급속 줌, 글리치 전환
  - 웃으며 엄지를 드는 작업자 (연출된 만족)
```

## 3. 보조 프롬프트 — 생성 영상이 필요할 때

> 위 스토리보드가 나온 뒤, **실사 촬영이 어려운 컷만** 영상 생성 AI로 채운다.
> ⚠ 생성 AI 는 화면 안 한글 텍스트를 제대로 못 쓴다. **자막은 반드시 후반에 얹는다.**

### 3-1. 1막 — 무게 (0–14초)

```
Extreme close-up, shallow depth of field. A pair of worn human hands grips the
edges of a cardboard box in a dim warehouse before dawn. The knuckles tighten.
The camera stays low and does not move. Cool blue-grey light from high windows,
dust drifting in the air. We never see the face. Photorealistic, cinematic,
35mm, natural light only, muted desaturated grade, 24fps.
No text, no logos, no on-screen writing, no robots.
```

### 3-2. 2막 전환 — 대신 (14–20초)

```
The same warehouse, the same spot on the conveyor line. A large industrial robot
arm, matte and unglamorous, lifts a cardboard box with unhurried, deliberate
motion and sets it onto a wooden pallet. The framing is wide and calm, as if
filming a piece of furniture rather than a machine. In the soft-focus background,
a person in work clothes stands still, simply watching. Cool blue-grey light.
Photorealistic, cinematic, slow static shot, 24fps.
No text, no logos, no on-screen writing, no dramatic lighting on the robot.
```

### 3-3. 4막 — 아침 (46–58초) ★ 영상의 목적

```
Warm early-morning sunlight fills a small apartment kitchen. A parent, still in
the clothes of a night shift, crouches down and lifts a small child up into
their arms in one easy motion. The child laughs. The camera holds steady at
their height and does not move. Golden amber light, soft shadows, shallow depth
of field, a little lens haze. Photorealistic, cinematic, tender, unstaged,
35mm, 24fps.
No text, no logos, no on-screen writing.
```

**생성 공통 파라미터**

| 항목 | 값 |
|---|---|
| 화면비 · 해상도 | 16:9 · 1080p 이상 |
| 프레임 | 24 fps (영화 톤) |
| 클립 길이 | 8초 |
| 카메라 | **고정 또는 아주 느린 이동만** |
| 네거티브 프롬프트 | `text, letters, subtitles, watermark, logo, HUD, hologram, scan lines, glowing eyes, cute robot, thumbs up, fast cuts, lens flare overload, distorted hands` |

## 4. 검수 체크리스트

프롬프트 결과물이 아래를 **하나라도 어기면 다시 시킨다.**

- [ ] 금지 단어(센서·알고리즘·AI·데이터·시스템·효율·%…)가 **0회**인가
- [ ] **숫자가 한 개도 없는가**
- [ ] 첫 10초에 로봇이 안 나오는가
- [ ] 로봇을 의인화하거나 영웅처럼 찍지 않았는가
- [ ] 나레이션이 **110음절 이하**인가 (넘으면 화면을 못 보게 된다)
- [ ] 마지막 컷이 **사람**인가 (로봇으로 끝나면 이 기획은 실패다)
- [ ] 팩트 시트에 없는 사실(통계·고객사·수상)을 지어내지 않았는가
- [ ] 실외 주행·배달 장면이 섞여 들어오지 않았는가 (이 로봇은 한자리에 서서 일한다)
- [ ] 58초를 넘지 않는가

## 5. 왜 이렇게 기획했는가 — 발표에서 물어보면

| 질문 | 답 |
|---|---|
| "왜 로봇을 안 보여주고 시작하나" | 제품을 먼저 보여주면 **광고가 된다.** 사람을 먼저 보여주면 **이야기가 된다.** Apple 이 아이폰 광고에서 아이폰을 20초 뒤에 꺼내는 이유와 같다 |
| "왜 성능 수치를 안 쓰나" | 수치는 **비교를 부른다.** 이 영상은 우열을 다투지 않는다. 수치는 발표 본편에서 쓴다 |
| "왜 마지막이 아이를 안는 장면인가" | 1막과 **완전히 같은 동작**이다. 무언가를 들어 올린다. 달라진 것은 무게가 아니라 **그 무게가 남긴 것**이다 |
| "왜 실내 물류센터만 나오나" | 이 시스템이 일하는 곳이 거기다. **없는 장면을 넣으면 광고가 거짓말이 된다** |
| "감성적인데 기술은 어디 갔나" | 이 영상 뒤에 바로 기술 발표가 온다. **영상은 왜(why)를, 발표는 어떻게(how)를 맡는다.** 한 자료가 둘 다 하려 들면 둘 다 흐려진다 |
