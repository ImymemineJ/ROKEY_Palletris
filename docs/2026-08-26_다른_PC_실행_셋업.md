## 4. 환경변수 — `run_test3.sh` 가 잡아 주는 값 (= 오늘의 정본)

| 변수 | 값 | 뜻 |
|---|---|---|
| `PL_STAGE` | `~/isaac_scenes/Collected_test_3/test_3.usd` | 씬 |
| `PL_CONFIG_OVERLAY` | `src/packing_bringup/config/test_3.yaml` | **좌표 오버레이. 빠지면 팔레트 자리가 전부 틀린다** |
| `PL_ZONES` | `A,B,C` | 로봇 3 대 동시 |
| `PL_N` | `33` | 박스 수 (배송지 3 곳 → 존당 약 11) |
| `PL_PER_PALLET` | `0` | 0 = 팔레트를 채울 때까지 쌓는다 (1 이면 한 개 놓고 반출) |
| `PL_METER` | `2` | 한 존 지선에 허용할 박스 수 |
| `PL_ROUTE` | `1` | 소터 라우팅 |
| `PL_CAM` | `1` | 픽업 좌표 인식 |
| `PL_CAMVIEW` / `PL_WRISTROS` | `0` / `0` | 부가 화면·ROS 발행 끔 |

`run_demo.sh` 가 추가로 잡는 것 — **이 둘은 아직 yaml 로 못 옮긴다** (모듈 import 시점에 읽힌다):

| 변수 | 값 | 읽는 곳 |
|---|---|---|
| `PL_DROP_KG` | **3.5** | `packing_robot/cycle.py` |
| `PL_CONTACT_STOP` | **1** | `packing_sim/isaac/robot_motion.py` |

> ★ `PL_DROP_KG` 는 `system.yaml` 의 `drop_max_kg` 와 **같아야 한다.**
> 어긋나면 계획이 연 자리를 로봇이 거부한다.
> ⚠ `run_demo.sh` 를 안 거치고 직접 `isaac-sim.sh --exec` 를 부르면 **직접 export 해야 한다.**

`LD_LIBRARY_PATH` 도 `run_demo.sh` 가 exec **전에** 잡는다
(`$ISAAC_DIR/exts/isaacsim.ros2.bridge/jazzy/lib`). 프로세스가 뜬 뒤 `os.environ` 을
고쳐도 소용없다 — glibc 가 시작 때 읽는다.

### 자주 쓰는 변형
```bash
PL_ZONES=A ./scripts/run_test3.sh          # 한 대만
PL_N=6 ./scripts/run_test3.sh              # 짧게
PL_PER_PALLET=1 ./scripts/run_test3.sh     # 반출만 보기
PL_NOWINDOW=1 ./scripts/run_test3.sh       # 창 없이 (약 7 배속, Play 자동)
PL_RATE=120 ./scripts/run_test3.sh         # 약 2 배속
```
⚠ `PL_RATE` 는 **사이클 시간을 재는 실행에 쓰지 마라** — `cycle.MOTION_POLL_S` 가
벽시계 기준이라 인공물이 늘어난다. 그리고 라우터 폴링이 벽시계 0.15 s 인데 분기
창이 시뮬 0.58 s 라, 배속을 올리면 **소터가 박스를 놓친다.**
(본 장비 실측: `PL_RATE=1200` 을 줘도 실제로는 **약 1.07 배**밖에 안 나온다 — 기계 한계)

## 5. ROS 를 쓸 때만 필요한 것 (기본은 안 쓴다)

`PL_WRISTROS=1` 로 손목 카메라를 `/wrist_cam/rgb` 로 쏠 때만:

```bash
export ROS_DOMAIN_ID=115
export RMW_IMPLEMENTATION=rmw_fastrtps_cpp
export FASTRTPS_DEFAULT_PROFILES_FILE=$HOME/.ros/fastdds_whitelist.xml
```

> ★★ **`fastdds_whitelist.xml` 이 다른 PC 에서 제일 조용하게 망가지는 것이다.**
> 현재 파일은 인터페이스를 `127.0.0.1` 과 **`10.10.0.1~4`** 로 못 박아 뒀다.
> 그 대역에 없는 장비는 **에러 없이 토픽이 하나도 안 보인다.**
> - 혼자 돌릴 거면 그냥 **이 변수를 export 하지 마라** (기본 전송으로 돈다)
> - 팀 대역에서 돌릴 거면 `scripts/fastdds_whitelist.xml` 을 `~/.ros/` 로 복사하고
>   `<address>` 를 **그 PC 의 실제 IP** 로 고칠 것 (`ip -4 addr`)

보기:
```bash
ros2 run rqt_image_view rqt_image_view /wrist_cam/rgb
```
