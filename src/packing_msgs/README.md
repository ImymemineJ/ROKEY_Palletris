# packing_msgs — ★ 초안입니다

**소유: 트랙 D (민범진).** 이 파일들은 트랙 C(정정인)가 Day 3 통합 시연을 막지 않으려고
먼저 작성한 초안입니다.

- 필드 이름·타입·순서는 `docs/작업명세서.md` §2.1 / §2.2 를 **한 글자도 바꾸지 않고** 옮겼습니다 (철칙 5).
- **srv 파일 이름만 제안값**입니다 (명세서가 서비스 경로만 정하고 타입 이름은 안 정함).
  예: `/algo/plan_placement` → `PlanPlacement.srv`
- 철칙 1: **`main` 에 먼저 머지하고 전원이 pull** 한 뒤에 쓰기 시작합니다.

민범진님이 확인 후 그대로 쓰시거나 고쳐 주시면 됩니다. 이름이 바뀌면 트랙 C 는
`packing_algo/algo_service_node.py` 의 import 두 줄만 고치면 됩니다.
